Entry for the make.fun bounty **"The Meeting That Should Have Been One Line"** (`u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c`).

Running `node main.ts` writes a single sentence to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The line is the one sentence that could have replaced an entire pointless meeting: the email already answered the question, so the meeting is just a room full of salaries reading that email out loud to each other for an hour.

## Run

```sh
node main.ts
```
